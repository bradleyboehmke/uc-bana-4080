# BANA 4080 Course Materials

The vocabulary used to describe this course's weekly teaching materials and the ML concepts they repeat week to week.

## Weekly materials

**Lecture notebook**:
The Colab notebook that lets students run the code from a week's Tuesday slides, plus short Your Turn exercises that vary it. Shown to students as the "Tuesday Your Turn Notebook".
_Avoid_: Slide notebook, companion notebook

**Chapter notebook**:
The Colab notebook that holds all the code from one textbook chapter.
_Avoid_: Example notebook, companion notebook

**Your Turn**:
A short exercise inside a lecture notebook that students attempt during or after Tuesday's class.

**Lab**:
The Thursday in-class notebook, made of a guided review followed by challenges.
_Avoid_: Lab assignment, workshop

**Guided review**:
The first part of a lab, where students rerun and tweak Tuesday's workflow on the lecture's dataset with the TA leading.
_Avoid_: Guided reinforcement, walkthrough

**Challenge**:
An independent lab exercise whose results feed the week's homework quiz.

**Support ladder**:
The decreasing help across a lab's challenges: starter code with blanks, then an outline only, then on your own.

**Homework quiz**:
The Canvas quiz that asks for the numbers and interpretations students produced in the lab's challenges.
_Avoid_: Lab quiz

## Recurring ML ideas

**Baseline**:
The trivial model (predict the mean, or the majority class) that any real model must beat to be worth using.
_Avoid_: Lazy model (acceptable as an informal nickname on slides only)

**Test-set peeking**:
Making any modeling decision based on test-set performance, which makes the final test score optimistically biased.
_Avoid_: Test set contamination (describes the result, not the act)
