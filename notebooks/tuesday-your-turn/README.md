# Tuesday Your Turn Notebooks

This directory contains the in-class coding notebooks used during Tuesday lectures.

These are student-facing and follow the lecture for that week, containing:

- Guided examples
- Short "Your Turn" exercises with `# Your code here` placeholders
- Brief reflection prompts

Each deck in `slides/` links to its companion notebook here, and the notebook is
also linked from that week's module overview page in the book.

## Naming convention

`week-NN-lecture.ipynb`

Module 7 is the midterm project week — no lecture, so no notebook.
