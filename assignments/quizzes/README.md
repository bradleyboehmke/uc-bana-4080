# Quizzes

Student-facing reading quizzes, one per module, following the format used in
BANA 7025's `assignments/quizzes/`: a short header (module, chapters, points, time
limit, attempts) followed by numbered questions.

**These files must not contain answers.** Quizzes with answer keys live in
`instructor/quizzes/`, which is gitignored.

## Naming

`week-NN-quiz.md`, where NN is the week — which equals the module number.

## Status

No student-facing quizzes have been published here yet. The existing 4080 quizzes
(weeks 12 and 13, plus their homework quizzes) include `Correct Answer:` lines and
therefore live in `instructor/quizzes/`. To publish one, copy it here and strip the
answer and explanation lines.
