# Discussions

Canvas discussion prompts, one file per prompt, following the format used in
BANA 7025's `assignments/discussions/`.

## Naming

`week-NN-topic.md`, where NN is the week — which equals the module number.
For example: `week-01-introduce-yourself.md`, `week-03-pandas-documentation.md`.

## Status

Empty for now. BANA 4080 does not yet have discussion assignments written up in the
repo; they are currently managed directly in Canvas. Add them here as they are
authored so they live alongside the rest of the course materials.
